# Examples

Run one with `spark examples/<name>`, check it with `spark check examples/<name>`. CI checks all of them.
Reference pictures for `spark golden <dir> --golden examples/_golden/<name>.png` are in `_golden/`.

| Folder | One feature |
|---|---|
| `01-hello` | smallest 3D game |
| `02-input` | keyboard, mouse, gamepad |
| `03-physics` | rigid bodies, collisions |
| `04-draw-2d` | a 2D game with `draw.*` |
| `05-ui` | slider, checkbox, buttons |
| `06-save` | data that survives restarts |
| `07-timers-tweens` | `every`, tasks, tweens |
| `showcase/pbr-gallery`, `showcase/night-lights` | graphics showcases |
| `demo` | bigger playground: physics, custom shaders, sound |
| `hello` | the same idea in pure Rust |
