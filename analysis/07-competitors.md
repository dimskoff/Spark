## 7.2 Rust-движки подробнее

- **Bevy** — ECS-движок, крупнейшее Rust-сообщество. Сильные стороны: data-oriented ECS, современный рендер
  (clustered forward, CSM, TAA, SSR, atmosphere, Solari RT с DLSS-RR), BSN-сцены (0.19), feathers-виджеты для будущего
  редактора (0.20), Bevy Remote Protocol для внешних инструментов. Слабые: нет редактора, Rust для игр — высокий порог,
  ломающий API каждые 3-4 месяца, долгая компиляция. **Урок для Spark:** reflection (`bevy_reflect`) + удалённый протокол
  поверх него — ровно тот фундамент, которого Spark не хватает; сцены как текст.
- **Fyrox** — «Godot на Rust»: полный редактор сцен (FyroxEd), префабы, анимационные машины состояний, UI-фреймворк,
  навигация, звук с HRTF, lightmaps, плагины с hot reload. 1.0 вышла в марте 2026. Слабые: маленькое сообщество, Rust,
  графика средняя. **Урок:** у редактора можно добиться полноты силами небольшой команды, если всё построено на
  reflection и командах с undo с первого дня.
- **Macroquad / ggez / Comfy** — простые 2D-фреймворки «код-first». Macroquad показывает, как маленький API даёт
  быстрый результат и Web-сборку. Comfy заброшен — пример того, как движок без сообщества и уникальной ниши умирает.
- **Ambient** — заброшенный Rust-движок с WASM-скриптами и сетью «из коробки»; урок: слишком широкая цель без
  законченного вертикального среза.

## 7.3 Чем Spark хуже (честно)

1. Нет сцен и редактора сцен — хуже всех, кроме LÖVE/Bevy.
2. Графика отстаёт от Godot 4, Bevy, Fyrox, Unity, Unreal.
3. Нет частиц, навигации, сети, анимационных графов, террейна — это обязательные части «движка» для людей.
4. Нет Web/мобильных платформ.
5. Нет сообщества, плагинов, ассет-стора, уроков.
6. Производительность физики при 10k тел и CPU-скининг.

## 7.4 Чем Spark уже лучше

1. **Агентский цикл «написал → проверил → увидел → протестировал» встроен в движок**, а не прикручен плагином:
   `check --json`, `test` со сценариями, headless-скриншоты, golden-diff, MCP. У Godot это десятки разных сторонних
   MCP-плагинов разной зрелости.
2. **Один exe**, мгновенный `spark new` → `spark .` без установки редактора.
3. **Luau** — язык Roblox: огромный корпус кода в обучающих данных моделей, типизация, быстрый VM, безопасный sandbox.
4. **Строгость**: NaN, пути, флаги, неизвестные поля — ошибки с местом. Ни один из крупных движков так не страхует ИИ.
5. **Маленький API «одним способом»** — модель меньше путается, чем в Unity с тремя UI-системами и двумя системами ввода.
