## 1.3 Что уже есть и работает

**Рантайм:** Luau с hot reload, модули `require`, таймеры, корутины-задачи (`wait`, `wait_until`, `wait_event`), твины,
события с приоритетами и отложенные, сохранения (атомарная запись), watchdog бесконечных циклов (5 с), лимит памяти 1 ГиБ.

**3D:** примитивы и `Mesh.custom`, glTF 2.0 (скины, анимации), FBX 7.x, point/spot/sun, PBR metallic-roughness,
normal/ORM-карты, LOD по расстоянию, градиент/кубмап-небо с IBL, туман, HDR, 10 пост-эффектов, свои WGSL-шейдеры
поверхности и пост-обработки с hot reload, пониженное внутреннее разрешение.

**2D:** immediate-mode рисование (спрайты, атласы, TTF-текст, фигуры, слои), immediate-mode UI (кнопка, слайдер,
чекбокс, панель, прогресс, картинка, подпись).

**Физика:** rapier3d — dynamic/kinematic/static, 5 форм, сенсоры, CCD, character controller, raycast, события столкновений,
пикинг по мешам.

**Аудио:** kira — wav/ogg/mp3/flac, шины микшера, фейды, «3D» через громкость/панораму, слои музыки.

**Инструменты:** `spark new/check/test/build/docs/update/api/doctor/screenshot/inspect/golden/diff/mcp`, Spark Editor
(менеджер проектов, код, консоль, problems, вьюпорт с fly-камерой, превью ассетов, live-link к игре), Discord RPC.

**Релизы:** Windows x64, Linux x64, macOS arm64; установщики с проверкой SHA-256.
