# 11. Роадмап

Порядок задан зависимостями: сначала то, что дёшево и сразу улучшает опыт ИИ и закрывает юридические и
security-риски, потом фундамент (реестр, сцены, команды), на котором строятся редактор, графика и остальные системы.
После каждого этапа продукт целостный, и разработку можно поставить на паузу.

«Готово» = есть тест или замер, и его запускали. Каждый этап: маленькие коммиты, запись в CHANGELOG, обновление доков.

---

## Этап A — «Ноль тихих ошибок» + юридическая гигиена (1–2 недели)

| Задача | Критерий |
|---|---|
| Строгие глобалы: чтение/запись неизвестного глобала → ошибка с did-you-mean (`mth` → `math`) | тест `strict_globals.luau` |
| Проверка колбэков: глобальная функция, похожая на колбэк (`Update`, `fixedUpdate`, `Render`, `lateUpdate`) → ошибка в `check` | тест |
| События: список встроенных; `on()` с неизвестным встроенным именем → ошибка; пользовательское событие без `emit` → warning | тест |
| did-you-mean по полям объектов/материалов/опций; чистый traceback без `__mlua_*` и `[C]` | снимок вывода `check --json` |
| Коды ошибок `SPK-xxxx` + поля `message/hint/location/docs` в JSON | схема JSON в доках, тест |
| Исправить подсказку `task.spawn` → `task(fn)`; согласовать `every`/`obj:every` | тест |
| `math.random` сеется в headless/test, флаг `--seed` | тест детерминизма |
| `THIRD_PARTY_LICENSES` через `cargo-about`: в релизе, в `spark build`, команда `spark licenses` | файл в артефакте CI |
| `deny.toml` + `cargo deny check` в CI (лицензии + advisories) | зелёный шаг |
| `ASSETS.md` с происхождением каждого ассета | файл |
| Удалить `crates/spark-editor.zip`, промпты из `docs/dev` убрать, `STATE.md` свести | CLEANUP.md |
| Логи ошибок в папку данных пользователя (`%LOCALAPPDATA%/<game>/logs`), а не рядом с exe/скриптом | тест пути |

## Этап B — Безопасность и устойчивость (1–2 недели)

| Задача | Критерий |
|---|---|
| FBX: проверка всех индексов, лимит inflate; fuzz-цели FBX/glTF/pack/devtools/save | `cargo fuzz` 10 мин без паник в CI по расписанию |
| Убрать `unsafe env::remove_var` (передавать бэкенд параметром) | `#![forbid(unsafe_code)]` в core/script/project/api/devtools |
| Devtools: токен от редактора (`SPARK_DEVTOOLS_TOKEN`), отказ без токена; игнор `--devtools` в упакованных играх | интеграционный тест |
| Luau `sandbox(true)` + read-only встроенные таблицы | тест «нельзя переопределить `math`» |
| Вьюпорт редактора: `catch_unwind`, watchdog, лимит памяти; Play — отдельным процессом | тест: паника игры не роняет редактор |
| `ImageData` инварианты, `dist.rs` симлинки и `tar --`, установщики с откатом | тесты |
| Подпись релизов minisign по умолчанию + проверка в `spark update` | `RELEASING.md` |
| Golden на CI: перегенерировать на lavapipe, шаг блокирующий; MSRV-джоба 1.85 | CI зелёный |

## Этап C — Фундамент: реестр, сцены, команды (4–8 недель) ⭐ главный

| Задача | Критерий |
|---|---|
| ADR: формат сцены (TOML vs RON), reflection (свой vs `bevy_reflect`), компонентная модель | 3 ADR |
| `spark-reflect`: derive для компонентов, диапазоны, дефолты, доки | юнит-тесты |
| `Object` → узел + компоненты (Transform, Mesh, Material, Body, Light, Camera, Script, Tags) с сохранением текущего Luau API | все существующие тесты и примеры проходят без изменений |
| Генерация Luau-биндингов, `spark.d.luau`, `SPARK_API.md`, `api.json`, `llms.txt` из реестра | ручные копии удалены, drift-тест не нужен |
| Формат `.scene` v1 + `.prefab` с overrides; `scene.load/save`, `spawn(prefab)`; миграции | round-trip тест: load → save → тот же файл |
| Модель команд + undo/redo в `spark-core` | тесты команд |
| Скрипты на объектах (`script = "..."`, `props`), изоляция ошибок по объекту | тест: ошибка одного объекта не останавливает игру |
| Hot reload модуля без перезапуска игры, ассеты не перезагружаются | замер: сохранение в игре с 50 моделями < 100 мс |
| `spark mcp`: `scene_read`, `scene_apply(commands)`, `attach` к живой игре (пауза/шаг/снимок/команды) | MCP-тест |

## Этап E — Renderer 2.0 (8–12 недель, может идти параллельно с D)

Подробно в [04-graphics.md](04-graphics.md) §4.3. Кратко по порядку: линейные data-текстуры → формат вершин и полный glTF →
тонмаппинг/пресеты → CSM → GPU-скининг/morph → render graph + storage instancing + pre-pass + GPU-профилировщик → TAA →
HDR IBL/пробы → частицы и декали → clustered lighting.
Критерии: golden на 3 ОС, таблица времени проходов, 10k объектов ≥ 60 FPS.

## Этап F — Системы для «настоящих» игр (8–16 недель, по ADR на каждую)

| Система | Минимум |
|---|---|
| Ассеты | GUID `.meta`, `spark-import`, кэш, асинхронная загрузка, KTX2 |
| Физика | слои/маски коллизий, joints (hinge, fixed, spring), shape cast, overlap-запросы, dirty-sync (10k тел < 8 мс) |
| Анимация | блендинг, state machine (файл + редактор), root motion, IK (two-bone, look-at) |
| UI | retained UI с лейаутом (flex), якоря, масштабирование, фокус/геймпад, текстовое поле, список, стили; UI в сцене |
| Ввод | action-mapping (`input.action("jump")`), ребинд, файл привязок |
| Аудио | эффекты (reverb, lowpass), аудио-источник как компонент, occlusion (raycast) |
| Навигация | navmesh (recast-подобный, лицензия!), агенты, обход |
| 2D | тайлмапы, 2D-физика (rapier2d), камера 2D, спрайт-анимации |
| Локализация | `tr("key")`, CSV/TOML строк, шрифты-фолбэки |
| Сохранения | сериализация состояния сцены через реестр |

## Этап G — Платформы и экосистема (дальше)

- Web (wgpu WebGPU/WebGL2 + Luau в WASM) — сильный козырь для ИИ-игр.
- Android/iOS (после стабилизации ввода и UI).
- Сеть: простой клиент-сервер с репликацией компонентов через реестр (ADR).
- Плагины (крейты + Luau-пакеты), менеджер пакетов `spark add`.
- Жанровые шаблоны (fps, platformer-2d, top-down, racing, puzzle) и CC0-библиотека ассетов.
- Сайт документации (mdBook), исполняемые примеры в доках, уроки.
- Агентский бенчмарк в CI по расписанию.
